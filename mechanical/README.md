# Printed bottom frame mockup (not for print yet)

- `printed_frame_mockup.step`: the frame as a solid, in the coordinates of Framework's graphics-module
  assembly, so it overlays `FW_GRAPHICS_MODULE_REF_00-1.stp`.
- `printed_frame_mockup.stl`: the same, meshed (binary, watertight).
- `preview/`: renders, with the adapter board (green), MXM socket (red), ear pads (yellow) and card
  (blue) where shown.

They are generated by `../generate_frame.py`; see `../FRAME_PLAN.md` for what was changed, the fit
check, and what to check before printing.
